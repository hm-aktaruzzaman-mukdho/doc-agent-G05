| 1 Ingest+Enhance |  Load scanned images with stable document/page IDs and improve OCR readability without changing source files. | Images under `data/raw/`; existing completed OCR Markdown may bypass image ingest during index-only rebuilds. | Deterministic OpenCV deskew, non-local-means denoise and adaptive binarization; generative enhancement is honestly disabled. | Recursively discover supported image formats, preserve `Page.id`/`doc_id`, and write cleaned images to `data/interim/preprocessed` only when images exist. | `loader → preprocess → enhance` consumes and returns the fixed `Page` contract; empty input remains valid for precomputed OCR mode. | Pytest checks discovery, stable IDs, preprocessing output and identity enhancement; parameters live in `config.yaml`. | CPU preprocessing is an offline batch before GPU OCR; raw scans are never overwritten. | Track source paths and stable IDs; validate unreadable images and failed output writes; keep generated interim images gitignored. |
| 2 Layout | Find OCR-ready text and table regions in reading order while retaining each page identity. | Preprocessed page images plus their fixed `Page` metadata. | OpenCV adaptive thresholding, morphology, contour proposals and ruling-line table detection adapted from `dl-ocr-parallel.py`. | Connect nearby text strokes, detect horizontal/vertical table grids, filter small contours, merge overlapping boxes and sort top-to-bottom then left-to-right. | Emit fixed `Region(page_id, bbox, kind)` objects and register the page image/doc mapping required by the fixed contract for downstream OCR. | Synthetic-page tests verify non-empty ordered regions and the OCR image-path bridge; invalid images fail explicitly. | Lightweight CPU layout pass; EasyOCR remains the GPU stage. | Monitor pages that fall back to one full-page text region and table/text proposal counts for layout drift. |
| 3 OCR | Recover searchable Bangla text while retaining a page id for every passage. | 432 pages from the History (194) and Geography (238) OCR Markdown outputs; page boundaries are `## Page N`. | EasyOCR 1.7.2 with the `bn` recognizer; Qwen/Qwen3.5-4B structural refinement from `dl-ocr-parallel.py`. | EasyOCR runs at batch size 8 on CUDA; Qwen restores headings, lists and tables without intentionally respelling OCR text; completed Markdown is reused during index rebuilds. | `transcribe()` emits one `Chunk` per page with stable `doc_id:page:NNNN` provenance; `Reader` handles unseen image regions. | Pytest covers page parsing/citations and EasyOCR reading order; all OCR choices live in `config.yaml`. | Full-book OCR is an offline GPU batch; routine knowledge-base builds read the saved output instead of spending GPU time again. | Pin model identifiers and OCR parameters; monitor missing/empty pages plus CER/WER on `grading_kit/labels.jsonl`. |
| 4 Index | Make 432 OCR pages semantically searchable without losing book/page provenance. | History and Geography page chunks from Stage 3; 1,294 indexed chunks in the current artifact. | Chonkie TokenChunker, BAAI/bge-m3 (1,024 dimensions), normalized FAISS IndexFlatIP; BM25 and BAAI/bge-reranker-v2-m3 provide the A2 retrieval check. | Split each page separately at 384 tokens with 64-token overlap; batch 16 on CUDA; exact cosine search through normalized inner product, fused with BM25 by reciprocal-rank fusion and reranked. | `Chunk.page_ids` survives chunking, storage, loading and retrieval; `chunks.jsonl` remains position-aligned with `index.faiss`. | Unit tests use a tiny deterministic FAISS fixture; `scripts/build_index.sh` is the single rebuild command; `kb_demo.ipynb` shows statistics and top-5 pages. | Offline GPU batch build; query embeddings and reranking use CUDA while FAISS exact search runs locally. | `manifest.json` records model, dimension, chunk settings, device and corpus coverage; loader rejects missing or vector/metadata count mismatches. |

AI:
The notebook has:

1. Dual-GPU full-page Qwen pipeline
   Every page becomes an image, half go to each GPU, and Qwen transcribes the entire page. It is simple but slow, VRAM-heavy, and more prone to omissions or hallucinations.

2. Hybrid layout-aware pipeline
   It extracts native PDF text when available; otherwise EasyOCR handles prose, while Qwen handles maps, figures, tables, and low-confidence pages.

For a clearly printed Bengali book, I recommend the hybrid pipeline:

- First try native text extraction with PyMuPDF.
- If the page is scanned, run EasyOCR on the page.
- Keep EasyOCR output when confidence is good.
- Escalate only poor pages to Qwen.
- Send maps and tables to Qwen separately only when present.

Use:

    USE_QWEN = True
    DUAL_GPU_QWEN = False
    PROSE_ENGINE = "hybrid"

This is preferable because it is much faster than running Qwen on every page, extracts native text without OCR errors, reserves Qwen for difficult content, and lowers the chance of Qwen hallucinating or paraphrasing Bengali text.

One qualification is that EasyOCR can still make errors in Bengali spelling and conjunct characters. For maximum accuracy, EasyOCR should be compared against a Bengali-capable PaddleOCR model on 10–20 representative pages. Between the two pipelines already present in the notebook, however, the hybrid one is preferable.

For a simple prose-only PDF, the pipeline can be reduced to:

Native-text extraction → EasyOCR for scanned pages → Qwen only for failed or low-confidence pages.

```bash
cd "/home/risenfromashes/Downloads/IFTI/dl project/doc-agent-G05"
source "../../.venv/bin/activate"
```

Then run:

```bash
PYTHONPATH=src python - <<'PY'
from doc_agent import config
from doc_agent.retrieval.retriever import Retriever

question = input("Enter your question: ")

retriever = Retriever(config.load())
results = retriever.retrieve(question, k=5)

for rank, result in enumerate(results, start=1):
    print(f"\n{rank}. {result.page_ids[0]} | score={result.score:.4f}")
    print("-" * 80)
    print(result.text)

retriever.release_models()
PY
```

You will see:

```text
Enter your question:
```

Type your Bangla or English question and press Enter.

## Generate a complete answer

The original `rag.py` already includes Qwen answer generation. Run it from the main IFTI directory:

```bash
cd "/home/risenfromashes/Downloads/IFTI"
source ".venv/bin/activate"

python rag.py "ছয় দফা কর্মসূচির গুরুত্ব কী ছিল?"
```

This will:

1. Retrieve five chunks.
2. Show their book and page numbers.
3. Load Qwen on the GPU.
4. Generate a grounded answer with citations.

For retrieval only, without Qwen generation:

```bash
python rag.py "ছয় দফা কর্মসূচির গুরুত্ব কী ছিল?" --no-generate
```

You do not need to rebuild the index—it already contains 1,294 chunks. Only run `bash scripts/build_index.sh` if the OCR text changes, because it will regenerate and overwrite the existing index.

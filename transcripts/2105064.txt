### 1. `layout.py` Architecture

`layout.py` must only care about **where** content is and **what type** it is, never what text it says.

* **Primary Function:** `detect_regions(page: Page) -> list[Region]`
* **Workflow:**
1. **Cache Resolution:** Checks if precomputed region metadata exists on disk (e.g., `cache/layout/{doc_id}_{page_id}.json` or derived directly from the precomputed OCR bounding boxes).
2. **Fallback Detection:** If no cache exists, runs document layout analysis (DLA) or contour-based column splitting on `page.image_path`.
3. **Reading-Order Sorting:** Applies multi-column top-to-bottom, left-to-right sorting (critical for textbook sidebars and two-column geography layouts).
4. **Contract Output:** Returns standard `Region(page_id=page.id, bbox=(x0, y0, x1, y1), kind="paragraph"|"header"|"caption"|"table")`.

### 2. `ocr.py` Architecture

`ocr.py` consumes the geometric regions produced by `layout.py` and populates the text content into `Chunk`s.

* **Primary Function:** `extract_chunks(page: Page, regions: list[Region]) -> list[Chunk]` (or equivalent repository signature like `ocr_region(page: Page, region: Region) -> str`).
* **Workflow:**
1. **Cache-First Lookup:** Uses `(page.doc_id, page.id)` to check the precomputed EasyOCR/Qwen output files (`cache/ocr/{doc_id}/{page.id}.json`).
2. **Spatial Intersection Matching:**
* When reusing saved OCR, maps the precomputed word/line bboxes into the requested `Region.bbox` using Intersection-over-Area (IoA) or center-point containment.
* Concatenates matched tokens/lines in reading order.


3. **Live Fallback (Unseen Pages):**
* If cache misses, crops `page.image_path` to `region.bbox`.
* Invokes the live OCR engine (EasyOCR Bangla model) and cleans up output with basic rule-based post-processing.


4. **Chunk Assembly:** Constructs the immutable `Chunk` objects incorporating region texts, page reference, and sequence order.

### `layout.py` Implementation

```python
from pathlib import Path
from typing import NamedTuple
import cv2
import numpy as np


# Assuming fixed contract dataclasses from the repo:
class Region(NamedTuple):
    page_id: str | int
    bbox: tuple[int, int, int, int]  # (x0, y0, x1, y1) in integer pixels
    kind: str  # "table" | "paragraph"


class Page(NamedTuple):
    id: str | int
    image_path: str
    doc_id: str | int


def _binarize(gray: np.ndarray) -> np.ndarray:
    """Otsu thresholding with inversion: foreground text/lines become 255."""
    blur = cv2.GaussianBlur(gray, (3, 3), 0)
    _, binary = cv2.threshold(blur, 0, 255, cv2.THRESH_BINARY_INV + cv2.THRESH_OTSU)
    return binary


def _extract_tables(binary: np.ndarray, min_area: int) -> tuple[list[tuple[int, int, int, int]], np.ndarray]:
    """Detects ruled tables via orthogonal morphological line kernels."""
    h, w = binary.shape
    h_kernel_len = max(20, w // 30)
    v_kernel_len = max(20, h // 30)

    # Extract horizontal lines (preserves table borders, cuts broken text matras)
    h_kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (h_kernel_len, 1))
    h_lines = cv2.morphologyEx(binary, cv2.MORPH_OPEN, h_kernel)

    # Extract vertical lines
    v_kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (1, v_kernel_len))
    v_lines = cv2.morphologyEx(binary, cv2.MORPH_OPEN, v_kernel)

    # Intersect lines to isolate table grid structures
    table_grid = cv2.add(h_lines, v_lines)
    dilate_kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (5, 5))
    table_grid = cv2.dilate(table_grid, dilate_kernel, iterations=2)

    contours, _ = cv2.findContours(table_grid, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

    table_boxes = []
    table_mask = np.zeros_like(binary)

    for cnt in contours:
        x, y, bw, bh = cv2.boundingRect(cnt)
        if (bw * bh) >= min_area and bw > (w // 10) and bh > (h // 20):
            bbox = (int(x), int(y), int(x + bw), int(y + bh))
            table_boxes.append(bbox)
            # Mask out detected tables to avoid duplicate text detection inside tables
            cv2.rectangle(table_mask, (x, y), (x + bw, y + bh), 255, -1)

    return table_boxes, table_mask


def _extract_text_blocks(
    binary: np.ndarray,
    table_mask: np.ndarray,
    min_area: int
) -> list[tuple[int, int, int, int]]:
    """Merges words into paragraph blocks using horizontal-dominant dilation."""
    h, w = binary.shape

    # Zero out table regions
    text_only = cv2.bitwise_and(binary, cv2.bitwise_not(table_mask))

    # Connect Bangla glyphs and inter-word spaces horizontally while preserving line spacing
    # Matra (headline) connects glyphs, so a wider horizontal kernel captures the full line/block
    h_block = max(15, w // 50)
    v_block = max(4, h // 180)
    block_kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (h_block, v_block))
    
    merged = cv2.morphologyEx(text_only, cv2.MORPH_CLOSE, block_kernel)
    merged = cv2.dilate(merged, block_kernel, iterations=1)

    contours, _ = cv2.findContours(merged, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

    text_boxes = []
    for cnt in contours:
        x, y, bw, bh = cv2.boundingRect(cnt)
        # Filter out minor scan artifacts/speckles
        if (bw * bh) >= min_area and bw >= 8 and bh >= 8:
            text_boxes.append((int(x), int(y), int(x + bw), int(y + bh)))

    return text_boxes


def _sort_reading_order(
    boxes: list[tuple[tuple[int, int, int, int], str]],
    line_tolerance: int = 15
) -> list[tuple[tuple[int, int, int, int], str]]:
    """
    Sorts regions top-to-bottom, left-to-right.
    Groups regions with near-identical Y-coordinates into bands before sorting on X.
    """
    if not boxes:
        return []

    # Sort strictly by top Y first
    boxes.sort(key=lambda item: item[0][1])

    # Group into spatial horizontal bands
    bands: list[list[tuple[tuple[int, int, int, int], str]]] = []
    for box in boxes:
        if not bands:
            bands.append([box])
            continue

        curr_top = box[0][1]
        band_top = bands[-1][0][0][1]

        if abs(curr_top - band_top) <= line_tolerance:
            bands[-1].append(box)
        else:
            bands.append([box])

    # Sort each band by left X coordinate and flatten
    sorted_boxes = []
    for band in bands:
        band.sort(key=lambda item: item[0][0])
        sorted_boxes.extend(band)

    return sorted_boxes


def detect_regions(page: Page) -> list[Region]:
    """
    Detects table and paragraph regions from a textbook page image.
    Guarantees non-overlapping table/text proposals and valid reading order.
    """
    img_path = Path(page.image_path)
    if not img_path.is_file():
        # Fallback 1: Missing file fallback
        return [Region(page_id=page.id, bbox=(0, 0, 100, 100), kind="paragraph")]

    gray = cv2.imread(str(img_path), cv2.IMREAD_GRAYSCALE)
    if gray is None:
        return [Region(page_id=page.id, bbox=(0, 0, 100, 100), kind="paragraph")]

    h, w = gray.shape
    min_area = int((w * h) * 0.0005)  # 0.05% of page area threshold

    try:
        binary = _binarize(gray)
        table_boxes, table_mask = _extract_tables(binary, min_area)
        text_boxes = _extract_text_blocks(binary, table_mask, min_area)

        tagged_boxes: list[tuple[tuple[int, int, int, int], str]] = [
            (bbox, "table") for bbox in table_boxes
        ] + [
            (bbox, "paragraph") for bbox in text_boxes
        ]

        # Order top-to-bottom, left-to-right
        sorted_tagged = _sort_reading_order(tagged_boxes, line_tolerance=max(12, h // 100))

        if not sorted_tagged:
            # Fallback 2: No contours passed threshold -> return full page
            return [Region(page_id=page.id, bbox=(0, 0, int(w), int(h)), kind="paragraph")]

        return [
            Region(page_id=page.id, bbox=bbox, kind=kind)
            for bbox, kind in sorted_tagged
        ]

    except Exception:
        # Fallback 3: Algorithmic crash fallback -> return safe full-page region
        return [Region(page_id=page.id, bbox=(0, 0, int(w), int(h)), kind="paragraph")]

```

### Core Operations & Justification for the A2 Report

* **Scale-Adaptive Orthogonal Line Filtering:**
* Ruled tables are isolated by morphological opening with long horizontal `(W/30, 1)` and vertical `(1, H/30)` structural elements.
* Because Bangla script contains continuous horizontal headlines (*matra* / মাত্রা), short kernels often false-trigger on text lines. Setting the kernel length relative to page width ($\ge W/30$) ensures only continuous structural grid lines survive.


* **Mutual Exclusion Masking (Zero-Overhead Deduplication):**
* When a table contour is found, its bounding box is drawn directly onto a binary `table_mask` with `cv2.rectangle(..., -1)`.
* Text block detection executes on `cv2.bitwise_and(binary, ~table_mask)`, eliminating duplicate proposals where individual table cells get re-detected as standard text paragraphs.


* **Bangla-Optimized Word Fusion:**
* A rectangular kernel with a high width-to-height ratio (`15:4` or `(W/50, H/180)`) bridges inter-word whitespace without bridging paragraph line breaks.


* **Banded Reading-Order Sorting:**
* Pure Euclidean or single-axis coordinate sorting scrambles multi-column layouts. Grouping bounding boxes into Y-axis tolerance bands before sorting on $X_0$ guarantees correct standard textbook flow.



---

### Failure Modes & Fallback Strategy

* **Unruled / Borderless Tables:** If a table lacks explicit grid lines, orthogonal kernel filtering yields no intersections. The pipeline safely degrades: `_extract_tables` returns an empty list, and the entire table structure flows into `_extract_text_blocks`, preventing lost tokens.
* **Over-Segmentation / Low-Contrast Scans:** If Otsu binarization degrades due to heavy non-uniform bleed-through or zero contours survive the minimum area filter (`min_area = 0.05%`), the detector catches the empty list and emits a safe, full-page fallback: `Region(page_id=page.id, bbox=(0, 0, w, h), kind="paragraph")`.
* **Execution Errors:** Any unexpected image decode issue or OpenCV error is trapped in the `try-except` block, yielding a full-page bounding box so the downstream `ocr.py` parser never receives an empty or unhandled exception.

### `ocr.py` Implementation

```python
import json
from pathlib import Path
from typing import Any, NamedTuple
import unicodedata

import cv2
import numpy as np
import torch

# Assuming fixed dataclass contracts from repository
class Page(NamedTuple):
    id: str | int
    image_path: str
    doc_id: str | int


class Region(NamedTuple):
    page_id: str | int
    bbox: tuple[int, int, int, int]  # (x0, y0, x1, y1)
    kind: str


class Chunk(NamedTuple):
    chunk_id: str
    page_id: str | int
    text: str
    kind: str


class BanglaOCRReader:
    """
    Lazy-loading OCR reader using EasyOCR with strict hardware validation
    and line reconstruction from word/token bounding boxes.
    """

    def __init__(self, use_gpu: bool = True, cache_dir: str | Path | None = None):
        self.use_gpu = use_gpu
        self.cache_dir = Path(cache_dir) if cache_dir else None
        self._reader: Any = None

    def _init_reader(self) -> None:
        """Enforces hardware constraints and instantiates EasyOCR only upon first use."""
        if self._reader is not None:
            return

        if self.use_gpu:
            if not torch.cuda.is_available():
                raise RuntimeError(
                    "CUDA GPU acceleration was explicitly requested, but torch.cuda.is_available() is False. "
                    "Aborting to avoid silent fallback to an unconfigured CPU environment."
                )

        import easyocr

        # Lazy instantiation of EasyOCR model for Bangla + English numerals/words
        self._reader = easyocr.Reader(["bn", "en"], gpu=self.use_gpu)

    @property
    def reader(self) -> Any:
        self._init_reader()
        return self._reader

    # ----------------------------------------------------------------------
    # Unicode & Text Normalization Layer
    # ----------------------------------------------------------------------
    @staticmethod
    def normalize_bangla_text(text: str) -> str:
        """
        Normalizes Unicode representations for complex Bengali scripts.
        - Enforces NFC form (composed glyphs).
        - Replaces informal zero-width sequences and redundant diacritics.
        """
        if not text:
            return ""

        # Step 1: Canonical Decomposition followed by Canonical Composition
        text = unicodedata.normalize("NFC", text)

        # Step 2: Clean up conflicting zero-width joiners / non-joiners
        # \u200c = ZWNJ, \u200d = ZWJ
        # Retain necessary Hasanta-Ya-phala sequences while stripping orphaned zero-width chars
        text = text.replace("\u200b", "")  # Zero-width space

        # Step 3: Normalize common multi-character vowel sign sequences (e.g., e-kar + aa-kar -> o-kar)
        # ো (O-kar: U+09CB) instead of ে (E-kar: U+09C7) + া (Aa-kar: U+09BE)
        text = text.replace("\u09c7\u09be", "\u09cb")
        # ৌ (Ou-kar: U+09CC) instead of ে (E-kar: U+09C7) + ৗ (Ou-length mark: U+09D7)
        text = text.replace("\u09c7\u09d7", "\u09cc")

        # Step 4: Standardize Bengali Dari / Purna Viram (\u0964) vs standard pipe (|)
        text = text.replace("|", "\u0964")

        return " ".join(text.split())

    # ----------------------------------------------------------------------
    # Spatial Line Reconstruction & Geometry
    # ----------------------------------------------------------------------
    @staticmethod
    def _reconstruct_lines(
        raw_results: list[tuple[list[list[int]], str, float]],
        y_tolerance_ratio: float = 0.5,
    ) -> str:
        """
        Reconstructs multiline paragraphs from unorganized word bounding boxes.
        raw_results format: [([[x0, y0], [x1, y0], [x1, y1], [x0, y1]], text, conf), ...]
        """
        if not raw_results:
            return ""

        parsed_tokens = []
        for box, text, _ in raw_results:
            xs = [pt[0] for pt in box]
            ys = [pt[1] for pt in box]
            x_min, x_max = min(xs), max(xs)
            y_min, y_max = min(ys), max(ys)
            y_center = (y_min + y_max) / 2.0
            height = max(1.0, float(y_max - y_min))
            parsed_tokens.append(
                {"text": text, "x": x_min, "y_center": y_center, "height": height}
            )

        # Primary sort: strictly top-to-bottom by vertical center
        parsed_tokens.sort(key=lambda t: t["y_center"])

        # Group words into lines using adaptive line-height threshold
        lines: list[list[dict[str, Any]]] = []
        for token in parsed_tokens:
            if not lines:
                lines.append([token])
                continue

            current_line = lines[-1]
            avg_line_y = sum(t["y_center"] for t in current_line) / len(current_line)
            avg_line_h = sum(t["height"] for t in current_line) / len(current_line)

            # Check if token lies on the same baseline band
            if abs(token["y_center"] - avg_line_y) < (avg_line_h * y_tolerance_ratio):
                current_line.append(token)
            else:
                lines.append([token])

        # Secondary sort: sort each line left-to-right by X coordinate
        reconstructed_lines = []
        for line in lines:
            line.sort(key=lambda t: t["x"])
            line_text = " ".join(t["text"] for t in line)
            reconstructed_lines.append(line_text)

        return "\n".join(reconstructed_lines)

    # ----------------------------------------------------------------------
    # Cache & Execution Entrypoints
    # ----------------------------------------------------------------------
    def _read_from_cache(self, doc_id: str | int, page_id: str | int) -> dict | None:
        """Attempts to load precomputed EasyOCR/Qwen data for the page."""
        if not self.cache_dir:
            return None

        # Look for precomputed structure cache: cache_dir/{doc_id}/{page_id}.json
        cache_path = self.cache_dir / str(doc_id) / f"{page_id}.json"
        if cache_path.is_file():
            try:
                with open(cache_path, "r", encoding="utf-8") as f:
                    return json.load(f)
            except Exception:
                return None
        return None

    def recognize_region(
        self, img_array: np.ndarray, bbox: tuple[int, int, int, int]
    ) -> str:
        """Crops the region from the page array and runs the recognition engine."""
        h, w = img_array.shape[:2]
        x0, y0, x1, y1 = bbox

        # Ensure bounds stay strictly within image boundaries
        x0, y0 = max(0, int(x0)), max(0, int(y0))
        x1, y1 = min(w, int(x1)), min(h, int(y1))

        if x1 <= x0 or y1 <= y0:
            return ""

        crop = img_array[y0:y1, x0:x1]
        raw_ocr = self.reader.readtext(crop)
        raw_text = self._reconstruct_lines(raw_ocr)
        return self.normalize_bangla_text(raw_text)

    def extract_chunks(self, page: Page, regions: list[Region]) -> list[Chunk]:
        """
        Processes all regions of a page, prioritizing precomputed OCR cache
        and falling back to live crop-level recognition.
        """
        cached_data = self._read_from_cache(page.doc_id, page.id)
        chunks: list[Chunk] = []

        # Case A: Saved OCR Reuse
        if cached_data and "regions" in cached_data:
            # Map precomputed text to requested regions based on ID or index
            for idx, r_data in enumerate(cached_data["regions"]):
                norm_text = self.normalize_bangla_text(r_data.get("text", ""))
                chunks.append(
                    Chunk(
                        chunk_id=f"{page.id}_c{idx}",
                        page_id=page.id,
                        text=norm_text,
                        kind=r_data.get("kind", "paragraph"),
                    )
                )
            return chunks

        # Case B: Live Crop Recognition for Fresh/Unseen Pages
        img = cv2.imread(page.image_path)
        if img is None:
            return chunks

        for idx, region in enumerate(regions):
            region_text = self.recognize_region(img, region.bbox)
            chunks.append(
                Chunk(
                    chunk_id=f"{page.id}_c{idx}",
                    page_id=page.id,
                    text=region_text,
                    kind=region.kind,
                )
            )

        return chunks

```

### Key Architectural & Validation Rules

* **Explicit Hardware Rejection:**
Rather than letting the engine silently degrade to CPU (which hides configuration errors and causes massive performance drops in batch OCR pipelines), `_init_reader()` validates `torch.cuda.is_available()`. If `use_gpu=True` is provided without an available device, it raises a `RuntimeError`.
* **Safe Sub-Pixel Integer Cropping:**
The `recognize_region` function explicitly bounds-checks the slicing indices `[y0:y1, x0:x1]` against the loaded image matrix dimensions `(h, w)` to eliminate negative coordinate indexing and empty slice crashes.
* **Vertical Band Clustering (Line Reconstruction):**
Word tokens returned by OCR engines have slight baseline noise. Grouping tokens where $\vert{}Y_{center} - Y_{band}\vert{} < 0.5 \times \text{Height}$ ensures multi-line Bangla text preserves top-to-bottom paragraph structure before horizontal left-to-right sorting occurs.
* **Bengali Unicode Integrity (NFC + Vowel Sequences):**
* `unicodedata.normalize('NFC', text)` merges disjoint base characters and vowel signs (*kar*s).
* Common composite vowel keystroke anomalies (such as writing *O-kar* as `E-kar + Aa-kar`) are mapped directly to standard single-code-point representations (`\u09cb`).
* Replaces pipe symbols (`|`) with standard Bengali Dari/Purna Viram (`\u0964`) and strips invisible zero-width spaces (`\u200b`).

```python
import re
from pathlib import Path
from typing import NamedTuple

# Fixed repository contracts
class Page(NamedTuple):
    id: str | int
    image_path: str
    doc_id: str | int


class Region(NamedTuple):
    page_id: str | int
    bbox: tuple[int, int, int, int]
    kind: str


class Chunk(NamedTuple):
    chunk_id: str
    page_id: str | int
    text: str
    kind: str


class PrecomputedMarkdownCorpus:
    """
    Parses and caches precomputed textbook OCR Markdown files.
    Supports History and Geography (Bhugol) textbooks.
    """

    ALLOWED_DOC_PREFIXES = ("history", "bhugol", "geography")

    # Matches headers like "## Page 1", "## Page 42", with optional whitespace
    PAGE_HEADER_PATTERN = re.compile(r"^##\s+Page\s+(\d+)\s*$", re.MULTILINE)

    def __init__(self, markdown_dir: str | Path):
        self.markdown_dir = Path(markdown_dir)
        # Store as: { doc_id: { page_num (int): clean_text (str) } }
        self._cache: dict[str, dict[int, str]] = {}
        self._load_corpus()

    def _validate_doc_name(self, file_path: Path) -> str:
        stem = file_path.stem.lower()
        if not any(stem.startswith(prefix) for prefix in self.ALLOWED_DOC_PREFIXES):
            raise ValueError(
                f"Invalid textbook document '{file_path.name}'. "
                f"Must start with one of {self.ALLOWED_DOC_PREFIXES}."
            )
        return file_path.stem

    def _clean_page_content(self, raw_text: str) -> str:
        """Strips markdown horizontal separators (---, ***) and excess whitespace."""
        # Remove markdown divider lines often generated between pages
        cleaned = re.sub(r"^\s*[-*_]{3,}\s*$", "", raw_text, flags=re.MULTILINE)
        return cleaned.strip()

    def _parse_file(self, file_path: Path) -> dict[int, str]:
        if not file_path.is_file():
            raise FileNotFoundError(f"Markdown file not found: {file_path}")

        try:
            content = file_path.read_text(encoding="utf-8")
        except Exception as e:
            raise ValueError(f"Failed to read {file_path.name} as UTF-8: {e}")

        matches = list(self.PAGE_HEADER_PATTERN.finditer(content))
        if not matches:
            raise ValueError(
                f"Malformed file '{file_path.name}': No '## Page N' headers found."
            )

        pages_map: dict[int, str] = {}
        total_matches = len(matches)

        for idx, match in enumerate(matches):
            page_num = int(match.group(1))

            # Content starts immediately after the current header line
            start_pos = match.end()
            # Content ends at the next header line or EOF
            end_pos = matches[idx + 1].start() if idx + 1 < total_matches else len(content)

            page_raw_text = content[start_pos:end_pos]
            clean_text = self._clean_page_content(page_raw_text)

            # Ensure page content is not completely blank/corrupt
            if not clean_text:
                raise ValueError(
                    f"Malformed file '{file_path.name}': Page {page_num} has empty text content."
                )

            pages_map[page_num] = clean_text

        return pages_map

    def _load_corpus(self) -> None:
        """Eagerly parses and validates all Markdown files in the directory."""
        if not self.markdown_dir.is_dir():
            return

        for md_file in self.markdown_dir.glob("*.md"):
            doc_id = self._validate_doc_name(md_file)
            self._cache[doc_id] = self._parse_file(md_file)

    def has_page(self, doc_id: str | int, page_num: int) -> bool:
        return str(doc_id) in self._cache and page_num in self._cache[str(doc_id)]

    def get_page_text(self, doc_id: str | int, page_num: int) -> str | None:
        return self._cache.get(str(doc_id), {}).get(page_num)
```

### Unified Extraction Pipeline (`ocr_pipeline.py`)

This pipeline seamlessly switches between precomputed whole-page Chunks and live Region OCR.

```python
import re
from typing import Any
from precomputed_loader import PrecomputedMarkdownCorpus, Page, Region, Chunk


class DocumentOCRService:
    def __init__(self, precomputed_corpus: PrecomputedMarkdownCorpus, live_ocr_reader: Any):
        self.precomputed = precomputed_corpus
        self.live_reader = live_ocr_reader  # Instance of BanglaOCRReader from previous step

    @staticmethod
    def _parse_page_number(page_id: str | int) -> int:
        """Extracts integer page number from page_id (e.g., 'page_12' -> 12, 12 -> 12)."""
        if isinstance(page_id, int):
            return page_id
        match = re.search(r"\d+", str(page_id))
        if match:
            return int(match.group(0))
        raise ValueError(f"Could not parse numeric page number from page_id: '{page_id}'")

    def process_page(self, page: Page, regions: list[Region]) -> list[Chunk]:
        """
        Primary entrypoint for indexing.
        1. Checks for precomputed Markdown page text (0 ms, zero GPU overhead).
        2. Falls back to live Region OCR for fresh/unseen pages.
        """
        page_num = self._parse_page_number(page.id)

        # -------------------------------------------------------------
        # Path A: Fast Precomputed OCR Reuse
        # -------------------------------------------------------------
        if self.precomputed.has_page(page.doc_id, page_num):
            text = self.precomputed.get_page_text(page.doc_id, page_num)
            normalized_text = self.live_reader.normalize_bangla_text(text)

            # Return a single full-page Chunk with a deterministic citation ID
            return [
                Chunk(
                    chunk_id=f"{page.doc_id}_p{page_num:03d}",
                    page_id=page.id,
                    text=normalized_text,
                    kind="page",
                )
            ]

        # -------------------------------------------------------------
        # Path B: Live OCR Engine Fallback for Held-Out Images
        # -------------------------------------------------------------
        return self.live_reader.extract_chunks(page, regions)
```

## Best pattern for dual T4

Use 2 independent workers, one per GPU:

- GPU 0: pages 1..mid
- GPU 1: pages mid+1..end

Each worker loads its own Qwen model on its assigned GPU, runs OCR on the assigned page images, and returns a result keyed by page number.

Then merge in order:

- page 1 output
- page 2 output
- ...
- page N output

This avoids mixing outputs by page and keeps the final markdown consistent.

---

## Why this is better than one model across both GPUs

For OCR page workloads, the bottleneck is usually not just "one model on two GPUs", but "many independent image jobs".

So model-per-GPU + page-level sharding is usually better than trying to split a single model across 2 GPUs with a single process. That split is more complex and can produce worse throughput for page-by-page OCR.

Also, for Kaggle dual T4, memory matters. A full vision model + image processing + KV cache can be heavy on each GPU, so running one model per GPU is simpler and more stable than a shared multi-GPU model instance.

## Root Cause

The model is loaded with `torch_dtype=torch.float16`, but the **processor outputs pixel values in float32 by default**. When you do:

## Root Cause #1 (Major): `repetition_penalty` Conflicts with Embedded OCR Text

> [!CAUTION]
> This is the **primary cause** of the ~2x slowdown AND likely degrades output quality.

In [`_run_qwen_generate()`](file:///d:/Code/Level_4_Term_1/CSE429_DL/A2/OCR_Notebook/OCR_NOtebook.py#L378-L386) (line 382):
```python

    **inputs,
    max_new_tokens=MAX_QWEN_NEW_TOKENS,
    do_sample=False,
    repetition_penalty=1.15,   # ← THE PROBLEM
    ...
)
```

HuggingFace's `repetition_penalty` checks **every generated token against ALL previous tokens, including the prompt**. In the old workflow, the prompt was ~30 tokens (just `QWEN_PROMPT_PROSE`). Now the prompt includes the full EasyOCR text — potentially **500–2000+ Bangla tokens**.

**Two harmful effects:**

1. **Slowdown**: Every decode step must scan the entire (now much longer) past context to apply the penalty. More tokens to check = slower per-step generation.

2. **Quality degradation**: The whole point is to KEEP the OCR spelling, but `repetition_penalty` **actively penalizes Qwen for reusing words from the OCR text in the prompt**. Qwen is forced to rephrase/avoid the exact Bangla words we want it to preserve, leading to either:
   - Garbled/alternative spellings (defeating the purpose)
   - Longer, rephrased outputs
   - Slower convergence to EOS

**Fix**: Use `repetition_penalty=1.0` (disabled) for structural refinement calls. The penalty was useful for the old pure-transcription prompt to prevent loops, but is counterproductive when we embed reference text.

---

## Root Cause #2 (Moderate): Longer Input Sequence → O(n²) Prefill

The old prompt: `image_tokens + ~30 text tokens`
The new prompt: `image_tokens + ~30 instruction tokens + 500–2000 OCR text tokens`

For Qwen VL, a 1200×1200 image produces ~1000–2000 image tokens. Adding 500–1500 OCR text tokens increases total input by **25–75%**. Since self-attention is O(n²):
- 1.3× tokens → 1.69× prefill time
- 1.5× tokens → 2.25× prefill time

This directly explains part of the ~2x overhead. **No easy fix** — this is inherent to embedding the OCR text. But fixing #1 above will reduce the total time significantly.

## Root Cause #3 (GPU Dependency): `torch.cuda.empty_cache()` Without Device Context

In [`_run_qwen_generate()`](file:///d:/Code/Level_4_Term_1/CSE429_DL/A2/OCR_Notebook/OCR_NOtebook.py#L396-L397) (line 396):
```python

```

This is called **after every single page**. `torch.cuda.empty_cache()` operates on the **current default CUDA device**, which is `cuda:0` unless explicitly set. When the GPU 1 thread calls this, it may:
- Empty GPU 0's cache instead of GPU 1's
- Cause implicit cross-GPU synchronization
- Explain why GPU 1 sometimes takes much longer (GPU 0's thread keeps clearing GPU 1's work)

**Fix**: Each thread must call `torch.cuda.set_device(device_id)` at the start, and `empty_cache` should be device-specific or removed from the per-page loop.
